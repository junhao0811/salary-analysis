# Tech Salary Analysis

Exploratory data analysis of **3,000+ tech salary records** in Python, with pandas and matplotlib.

## What it covers
- Data inspection and cleaning (types, missing values, summary statistics)
- Breakdown of 85 job titles, e.g. the share of Data Engineer vs Data Scientist roles
- Salaries by **country**, **company size** and **employment type** (full-time vs part-time)
- Bar-chart visualisations with written interpretation of each finding

## Files
- `salary_analysis.ipynb`: the full analysis notebook
- `salaries.csv`: dataset
- `report.pdf`: exported report

## Run it
```bash
pip install pandas matplotlib jupyter
jupyter notebook salary_analysis.ipynb
```
